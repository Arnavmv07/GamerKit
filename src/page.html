Why GamerKit exists

Every new build ends the same way. The parts are in, Windows boots, and then you spend an evening searching for Steam, Discord, the right GPU driver and Afterburner, one tab at a time, avoiding fake download sites along the way. GamerKit turns that evening into a few minutes.

Vision

A new gaming PC should be ready to play in minutes, not hours.

Mission

Gather every tool PC gamers rely on into one clean page, link only to official sources, and let anyone install the whole set in one go.

  • Official sources only

    Every button goes to the developer's own site. GamerKit never hosts or repackages an installer.

  • Always the latest version

    Links point to official download pages and winget fetches each app's newest release, so nothing goes stale.

  • Free, no sign-up

    No account, no paywall. Pick what you need and go.

Questions

What should I install first on a new gaming PC?

Start with your graphics driver (the NVIDIA App, AMD Software: Adrenalin or Intel's Driver & Support Assistant), then your game launchers such as Steam and the Epic Games Launcher, then Discord and a monitoring tool like HWiNFO or MSI Afterburner.

Is it safe to download from GamerKit?

GamerKit hosts no files. Each Download button opens the developer's official site, and the installer script uses winget, the package manager built into Windows 10 and 11.

How does the one-click install work?

Download everything, or your own kit, as a zip. Run "GamerKit Installer.bat". Windows asks for permission once, then winget installs each supported app silently at its latest version and skips any that are already up to date. If you would rather have the installer files, run "Download installers.bat" and they are saved into an Installers folder, fetched straight from each publisher. Tools without a winget package come as shortcuts to their official download pages.

Do I need to install DirectX or Visual C++ separately?

Usually not. Games install the runtimes they need during setup, so GamerKit leaves them out.

Will the apps stay up to date?

Most update themselves. You can also run "GamerKit Installer.bat" again at any time. It skips apps that are already up to date and updates the rest.
